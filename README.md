

## 🚀 MERN Stack AI Chatbot (ChatGPT-Inspired)

An intelligent, full-stack AI chatbot application built using the powerful **MERN stack** (MongoDB, Express, React, Node.js) and integrated with **OpenAI's GPT API**. This project brings ChatGPT-like capabilities to your own platform — fully customizable, secure, and production-ready.

### ✨ Features

* 🤖 **AI-Powered Conversations** – Chat with a GPT-based AI assistant in real time.
* 💾 **Persistent Chat History** – Each user message is stored in MongoDB and can be retrieved or deleted.
* 🔐 **Robust Security** – Includes JWT-based auth, HTTP-only cookies, signed cookies, password hashing (bcrypt), and middleware validation.
* 👤 **User Authentication** – Sign up, log in, and maintain sessions securely.
* 💬 **Responsive UI** – Clean and intuitive React frontend for smooth interaction.
* 📦 **Modular Backend** – Well-structured Express API with routes, middleware, and controllers.

### 🛠️ Tech Stack

* **Frontend:** React, Axios, Tailwind CSS
* **Backend:** Node.js, Express, OpenAI API, JWT, bcrypt
* **Database:** MongoDB (Mongoose)
* **Security:** JWT, HTTP-only cookies, cookie-signing, password encryption
